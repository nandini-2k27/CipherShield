# CipherShield - Encryption & Cryptanalysis Toolkit

CipherShield is a powerful and interactive cryptography toolkit built using Python and Streamlit. It allows users to encrypt, decrypt, and analyze text using modern and classical cryptographic techniques.

---

## Features

### Encryption Algorithms

- AES (Advanced Encryption Standard)
- RSA (Public Key Cryptography)
- Classical Ciphers:
  - Caesar Cipher
  - Vigenère Cipher

### 🕵️ Cryptanalysis Attacks

- Brute Force Attack
- Frequency Analysis Attack

###  Interactive UI

- Built with Streamlit
- User-friendly interface
- Real-time encryption/decryption

- Cryptography Libraries
